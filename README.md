# Трекер реабилитации пациентов

Веб-приложение для мониторинга выполнения реабилитационных упражнений, отслеживания прогресса и взаимодействия пациента с врачом/реабилитологом.

## Структура проекта
* `src/` — исходный код приложения (Django).
* `docs/` — проектная документация.
* `tests/` — модульные и интеграционные тесты.

## Стандарты разработки
Внимательно прочитайте [CONTRIBUTING.md](CONTRIBUTING.md) перед началом работы. Там описаны правила именования веток, стандарты кода (PEP 8) и процедура Code Review.
